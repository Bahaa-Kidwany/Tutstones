## 1. Brand Identity & Design Philosophy

TUT Stones combines **Egypt’s 5,000-year geological heritage** with **modern luxury architectural design**. The visual language is defined by rich stone textures, high-contrast Pharaonic color pigments (Terracotta Red, Nile Lapis Blue, Egyptian Gold), and classical typography.

---

## 2. Official Color Palette — Pharaonic Heritage Theme

The website is styled with the **Pharaonic Heritage Theme**, directly derived from ancient Egyptian temple frescoes, lapis lazuli, red ochre, and papyrus sandstone.

| Token Name | Hex Code | RGB Value | Usage & Application |
| :--- | :--- | :--- | :--- |
| **Egyptian Terracotta** | `#8D4F4E` | `rgb(141, 79, 78)` | Section tags, primary CTAs, active buttons, card borders |
| **Nile Lapis Blue** | `#567394` | `rgb(86, 115, 148)` | Subheaders, experience badges, secondary feature icons |

| **Hieroglyph Charcoal** | `#241C18` | `rgb(36, 28, 24)` | Primary readable body text & section titles |

## 3. Typography Hierarchy

Imported via Google Fonts:

```css
@import url('https://fonts.googleapis.com/css2?family=Cinzel+Decorative:wght@700&family=Cinzel:wght@500;600;700;800&family=Cormorant+Garamond:ital,wght@0,400;0,500;0,600;0,700;1,400&family=Plus+Jakarta+Sans:wght@300;400;500;600;700&display=swap');
```

| Element | Font Family | Weight | Size | Usage |
| :--- | :--- | :--- | :--- | :--- |
| **Hero Title** | `Cormorant Garamond`, Georgia, serif | `700` | `3.5rem` (`56px`) | Main home slider & page hero titles |
| **Section Title** | `Cormorant Garamond`, Georgia, serif | `600` | `2.75rem` (`44px`) | Section headers (`.section-title`) |
| **Pharaonic Accent** | `Cinzel`, `Cinzel Decorative`, serif | `700` | `2.2rem` (`35px`) | Decorative titles & emblems |
| **Body Copy** | `Plus Jakarta Sans`, sans-serif | `400 / 500` | `1.0rem` (`16px`) | Paragraphs & technical specifications |
| **Section Tag** | `Plus Jakarta Sans`, sans-serif | `600 / 700` | `0.825rem` (`13px`) | Uppercase pill tags (`.section-tag`) |
| **Button Text** | `Plus Jakarta Sans`, sans-serif | `600` | `0.95rem` (`15px`) | Interactive CTAs & dropdown links |
