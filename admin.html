Content Editor Role Guide

Learn how to set up, deploy, and assign restricted Content Editor accounts for team members.

Creating a Content-Only Admin Account

To ensure non-technical staff or client content managers can safely edit stone images, categories, hero slides, About text, and social links without risk of breaking developer settings or database schemas:

  1. Assign Role State: Set the user account role property to editor (Content Editor) rather than admin (Developer / Super Admin).
  2. Automatic Interface Lock: When logged in as editor, the Admin Panel automatically applies the CSS class mode-editor to the document body.
  3. Hidden Developer Tools: All technical developer components (such as Database Reset, Raw JSON Import/Export, and System Diagnostics) are automatically hidden from the navigation sidebar and interface.
  4. Streamlined Workflow: Content editors can comfortably update images via file upload or URL, preview category thumbnail grids, edit slider slides, update About copy, and toggle social media links.

1. Managing Images & Thumbnails

Click on Stone & Image Editor or Category Thumbnails. You can upload image files directly from your computer or paste image URLs. Use the category thumbnail gallery to preview images grouped by collection.

2. Editing Hero Slider

Navigate to Hero Slider Images. You can change background imagery, badge text, headings, and action button target links. Changes appear immediately on the main homepage slider.

3. Updating About & Social Links

Use About Us Editor to modify company copy, stats, and craft photo. Use Social Media Links to update Instagram, LinkedIn, Facebook, Pinterest, or WhatsApp links.
